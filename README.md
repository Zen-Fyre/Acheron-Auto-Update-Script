# [Acheron](https://github.com/ouwou/acheron) Auto Update Script
A simple [Acheron](https://github.com/ouwou/acheron) auto update batch script for Windows


## What does it do?
What the name implies.

And it will start Acheron as soon as it finishes updating


## Requirements
 * Win 8+ with Powershell
 * 7z (Best if installed, ex. NanaZip automatically makes the 7z env path available)

### Download

Slap this bad boi into the folder where Acheron will be installed and that's where it'll be unpacked, perhaps make it a shortcut of the script into WIN+X ``"shell:startup"``
